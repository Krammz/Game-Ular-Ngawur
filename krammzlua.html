Tentang koneksi

API yang digunakan belum mengizinkan akses langsung dari browser (CORS). Gunakan server pendamping agar chat dapat terhubung:

  1. Letakkan krammzlua.html dan jalankan_krammzlua.py di folder yang sama.
  2. Di Terminal, jalankan python jalankan_krammzlua.py (atau python3 di Linux/macOS).
  3. Buka http://127.0.0.1:8000 di browser, dan biarkan Terminal tetap terbuka.

Riwayat tampilan tersimpan di browser. Pesan juga dikirim ke penyedia API. Menghapus chat di sini tidak menghapus sesi yang mungkin tersimpan di server penyedia.
